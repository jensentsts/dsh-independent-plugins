# Artwork sources and remaining work

The package icon and geometric avatar SVGs were authored directly for this independent package and are distributed under the package MIT license. They use no official vendor mark or third-party character illustration.

The eight current model-family defaults are AI-generated original adult whale-girl portraits. Their 4×2 source sheet was generated through `image_generate` on 2026-11-10, requested provider `gpt`, without image references or artist/IP imitation. The source and all eight cropped 256×256 WebP files were visually inspected. Actual prompts, returned metadata, processing-tool versions, hashes and rights limitations are recorded in `artwork/GENERATION.md` and `artwork/avatar-manifest.json`; no stock-art license, human illustrator authorship, uniqueness guarantee or official vendor endorsement is claimed.

After the bundled-Python crop command and lead retry failed with WinError 5, the human explicitly authorized the unchanged script to use system Python 3.12.0 with existing Pillow 12.2.0 for this task only. It succeeded without installation, PATH changes or ACL changes. Each local WebP is 13,310–17,882 bytes and is embedded into this plugin's Client artifact; generic/user/unknown-family roles retain geometric SVG fallback artwork. Installed 28-pixel browser appearance still requires separate verification.

User-selected raster avatars remain under the user's rights and are stored only as bounded image data in that user's plugin settings. The plugin does not redistribute those selections as package artwork.
